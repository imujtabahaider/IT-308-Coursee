Mobile Programming Languages

Learn about the programming languages used to develop mobile applications, their features, and the difference between native and cross-platform development.

1. Introduction to Mobile Programming Languages

Mobile applications are software programs that run on mobile devices such as smartphones and tablets.

To develop these applications, programmers use different programming languages. These languages allow developers to create application interfaces, perform calculations, manage data, communicate with servers, access mobile hardware, and provide different services to users.

Definition:

A mobile programming language is a programming language used to develop applications for mobile devices such as smartphones and tablets.

For example:

  • Java is used to develop Android applications.
  • Kotlin is a modern language for Android development.
  • Swift is used to develop iOS applications.
  • Objective-C was traditionally used for iOS development.
  • Dart is used with Flutter to develop applications for multiple platforms.
  • JavaScript is used with frameworks such as React Native to build mobile applications.

Different programming languages have different features, advantages, and limitations.

2. Why Are Programming Languages Important in Mobile Development?

Programming languages are important because they provide instructions that tell a mobile device what an application should do.

Example: Calculator Application

Consider a simple calculator application.

When a user enters two numbers and presses the addition button, the application must:

  1. Receive the numbers entered by the user.
  2. Read the selected operation.
  3. Perform the addition.
  4. Calculate the result.
  5. Display the result on the screen.

A programming language is used to write the instructions for all these operations.

Programming languages also help developers:

  • Create application interfaces.
  • Handle button clicks and user interactions.
  • Store and retrieve information.
  • Connect applications to the internet.
  • Access cameras, GPS, microphones, and sensors.
  • Communicate with web servers.
  • Manage application performance and memory.
  • Develop secure mobile applications.

4. Native and Cross-Platform Programming Languages

Mobile programming languages are also understood according to the development approach they support.

There are two major approaches:

  1. Native application development.
  2. Cross-platform application development.
4.1 Native Application Development
Definition:

Native application development is the process of creating an application specifically for one operating system using its supported programming languages and development tools.

For example:

  • Android applications can be developed using Kotlin or Java.
  • iOS applications can be developed using Swift or Objective-C.
Example:

Suppose a company wants to create an application for Android.

It uses Kotlin and Android Studio to develop the application specifically for Android devices.

If the company also wants an iOS version, it may need a separate iOS implementation using Swift.

Advantages
  • Strong integration with device features.
  • Good performance.
  • Access to platform-specific APIs.
  • Native user-interface experience.
  • Better control over platform-specific functionality.
Limitations
  • Separate development may be needed for Android and iOS.
  • More development time may be required.
  • Maintaining two separate codebases can increase costs.
4.2 Cross-Platform Application Development
Definition:

Cross-platform application development is the process of developing an application using a shared codebase that can run on multiple operating systems, such as Android and iOS.

Examples include:

  • Flutter with Dart.
  • React Native with JavaScript or TypeScript.
  • .NET MAUI with C#.
Example:

Suppose a developer wants to create a shopping application for both Android and iOS.

Instead of creating two completely separate applications, the developer can use Flutter and Dart to share much of the application code between both platforms.

Advantages
  • Code can be reused across platforms.
  • Development time may be reduced.
  • Maintenance can be easier.
  • Fewer separate development teams may be needed.
Limitations
  • Some platform-specific features need additional implementation.
  • Performance depends on the framework and application requirements.
  • Native development knowledge may still be required.

Challenges with Mobility and Wireless Communication

Understand the problems mobile devices face when moving between locations and communicating through wireless networks.

1. Introduction

Mobile devices such as smartphones and tablets allow people to communicate, access information, and use applications from almost anywhere.

Unlike desktop computers, mobile devices are not connected to one fixed location or network. Users move from one place to another while using their devices.

For example:

  • A person uses a mobile application while travelling in a car.
  • A student attends an online class using mobile internet.
  • A user makes a video call while walking outside.
  • A delivery driver uses GPS and mobile data to find a customer's address.

Although mobile technology provides flexibility, it also creates several challenges.

These challenges are related to mobility, wireless communication, network availability, signal strength, security, speed, and connection reliability.

Definition:

Challenges with mobility and wireless communication are the problems that occur when mobile devices move between locations and communicate through wireless networks.

2. Understanding Mobility in Mobile Computing

Definition:

Mobility refers to the ability of users to move from one location to another while continuing to use mobile devices, applications, and network services.

In mobile computing, users are not required to remain connected to one fixed network or location.

Example:

A person can start watching a video at home, continue watching it while travelling, and finish it at a different location.

However, when the person moves, the device may experience changes in network coverage, signal strength, and connection quality.

2.1 Types of Mobility
  1. User Mobility

    User mobility means that a person can move from one physical location to another while using mobile services.

    Example:

    A student moves from home to university while using a smartphone.

  2. Device Mobility

    Device mobility means that a mobile device can move between different locations and network coverage areas.

    Example:

    A smartphone moves from one mobile network coverage area to another while travelling.

  3. Network Mobility

    Network mobility refers to situations where an entire network or group of connected devices moves from one location to another while maintaining network communication.

    Example:

    Passengers in a moving vehicle use a shared Wi-Fi network connected to a mobile internet connection.

3. Understanding Wireless Communication

Definition:

Wireless communication is the process of transmitting and receiving information between devices without using physical cables.

It uses electromagnetic waves, such as radio waves, to transfer information through the air.

For example:

  • Wi-Fi connects smartphones to wireless networks.
  • Bluetooth connects wireless headphones to smartphones.
  • Cellular networks provide mobile internet and calling services.
  • NFC allows short-range communication between nearby devices.

3.1 How Wireless Communication Works

Wireless communication generally involves the following steps:

  1. A device creates information that needs to be transmitted.
  2. The information is converted into a suitable wireless signal.
  3. The transmitting device sends the signal through an antenna.
  4. The signal travels through the air.
  5. A receiving device or wireless access point receives the signal.
  6. The received signal is converted back into information.
  7. The receiving device processes the information.
Example: Sending a Message

Suppose you send a message through a mobile messaging application.

  1. You type a message on your smartphone.
  2. The application prepares the message for transmission.
  3. Your phone sends the data through Wi-Fi or a cellular network.
  4. The network carries the data towards the messaging service.
  5. The service forwards the message to the receiver.
  6. The receiver's device receives and displays the message.

4. Major Challenges with Mobility and Wireless Communication

Mobile application developers face several challenges because mobile devices depend on wireless networks and frequently change locations.

The major challenges are explained below.

4.1 Limited Network Coverage
Definition:

Limited network coverage means that wireless network services are not available everywhere or may not provide a strong connection in every location.

Wireless signals have a limited coverage area. Some places receive strong signals, while others receive weak signals or no signals at all.

Example:

A person uses a mobile application inside a city where 4G or 5G services are available.

When the person enters a remote village, underground parking area, or mountainous region, the mobile network may become weak or unavailable.

Signal strength refers to the power of a wireless signal received by a device. Interference occurs when unwanted signals or obstacles affect wireless communication.

Wireless signals can become weak because of:

  • Long distances between devices and network equipment.
  • Walls and buildings.
  • Mountains and other physical obstacles.
  • Weather conditions in some wireless systems.
  • Other electronic devices and radio signals.

Definition:

Changing network conditions mean that the speed, quality, and reliability of a wireless connection can change over time and between locations.

Unlike a fixed wired connection, wireless network quality is not always constant.

For example, a user may experience:

  • Fast internet in one location.
  • Slow internet in another location.
  • Strong signals at one time.
  • Weak signals at another time.
Example:

A person is watching an online lecture.

At the beginning, the internet speed is high, so the video plays smoothly.

Later, the person enters an area with weak network coverage. The video starts buffering.

  • Use adaptive data transmission.
  • Reduce unnecessary network requests.
  • Provide loading indicators.

4.4 Network Disconnection
Definition:

Network disconnection occurs when a mobile device temporarily or permanently loses its connection to a wireless network.

It may happen because of:

  • Moving outside network coverage.
  • Turning on airplane mode.
  • Network equipment failure.
  • Weak signals.
  • Switching between wireless networks.
  • Mobile data or Wi-Fi being disabled.
Example:

A user is filling out an online registration form.

Before submitting it, the internet connection is lost.

If the application does not save the entered information, the user may lose the entire form.

Solutions:

  1. Save important information locally.
  2. Detect when the internet connection is lost.
  3. Display an appropriate warning.
  4. Retry failed requests when connectivity returns.
  5. Avoid losing user-entered data.
  6. Synchronize pending information when the device reconnects.
4.5 Handoff and Handover
Definition:

Handoff, also called handover, is the process of transferring an active wireless connection from one access point or cell to another while maintaining communication.

It is particularly important in cellular networks.

Imagine a person is travelling in a car while talking on a mobile phone.

Initially, the phone is connected to Cell Tower A.

As the car moves away from Tower A and approaches Tower B, the mobile network transfers the connection to Tower B.

Types of Handoff
  1. Hard Handoff

    In a hard handoff, the old connection is disconnected before the new connection is established.

    It is commonly described as a break-before-make process.

  2. Soft Handoff

    In a soft handoff, the device may maintain connections with more than one base station during the transition.

    It is commonly described as a make-before-break process.

Important:

The exact handoff methods depend on the wireless technology being used.

Problems during handoff:

  • Temporary connection interruption.
  • Dropped calls.
  • Data transmission delays.
  • Reduced network quality.

Solutions:

  • Efficient network handoff mechanisms.
  • Proper network coverage planning.
  • Fast connection switching.
  • Reliable session management.
4.6 Bandwidth Limitations
Definition:

Bandwidth is the maximum amount of data a network connection can transfer in a given period.

It is usually measured in bits per second, such as Mbps or Gbps.

A network with higher available bandwidth can generally transfer more data per second.

Example:

A user downloads a large video file using mobile internet.

If available bandwidth is low, the download takes longer.

If bandwidth is high, the file can usually download faster.

Problems caused by limited bandwidth:

  • Slow downloads.
  • Video buffering.
  • Delayed file uploads.
  • Poor online gaming experience.
  • Slow application responses.

Solutions:

  • Compress images and files.
  • Reduce unnecessary data transmission.
  • Load only the required information.
  • Use efficient data formats.
  • Provide lower-quality media options.
4.7 Latency and Delay
Definition:

Latency is the time taken for data to travel from a source to a destination across a network.

It is commonly measured in milliseconds (ms).

Low latency means that data travels with less delay, while high latency means that communication takes longer.

Example:

A person plays an online multiplayer game.

When the player presses a button, the action must travel to the game server and the server's response must return.

If latency is high, the action may appear late on the screen.

4.8 Security and Privacy Risks
Definition:

Wireless security risks are threats that can affect information transmitted or stored through wireless networks and mobile devices.

Wireless communication can expose information to security threats if appropriate protection is not used.

Common security risks:

  1. Unauthorized Access

    An unauthorized person may attempt to access a wireless network or mobile device.

  2. Data Interception

    Attackers may try to capture information transmitted over an insecure network.

  3. Man-in-the-Middle Attack

    An attacker may position themselves between two communicating parties to intercept or manipulate their communication.

  4. Fake Wi-Fi Hotspots

    Attackers may create wireless networks that look legitimate to trick users into connecting.

  5. Data Theft

    Sensitive information, such as login credentials or personal information, may be stolen.

Example:

A user connects to an unknown public Wi-Fi network and enters their account password on an insecure website.

An attacker may attempt to intercept the information.

Solutions:

  • Use HTTPS for secure communication.
  • Encrypt sensitive information.
  • Use secure authentication.
  • Avoid sending passwords through insecure connections.
  • Keep mobile applications and operating systems updated.
  • Use trusted Wi-Fi networks.
  • Apply appropriate access controls.
4.9 Power Consumption
Definition:

Power consumption refers to the electrical energy used by a mobile device while performing operations.

Wireless communication can consume significant battery power, especially when a device frequently searches for networks or transfers large amounts of data.

Example:

A user continuously streams videos using mobile data.

The phone's network hardware, display, processor, and other components remain active.

This can reduce battery life.

Solutions:

  • Reduce unnecessary network requests.
  • Avoid continuous background communication.
  • Use efficient data transmission.
  • Combine multiple network requests where suitable.

27.4.1 GPS (Global Positioning System)

Definition:

GPS is a satellite-based navigation system that helps devices determine their geographical position using signals received from satellites.

GPS satellites continuously transmit signals containing information about their positions and transmission times.

A GPS receiver in a smartphone uses signals from multiple satellites to calculate its position.

How GPS Works
  1. GPS satellites orbit the Earth.
  2. Satellites transmit signals containing timing and position information.
  3. A smartphone receives signals from multiple satellites.
  4. The GPS receiver calculates the distance to the satellites using signal travel time.
  5. It uses these distances to calculate the device's geographical position.
  6. The application uses the calculated location.

Usually, signals from at least four satellites are used for a standard three-dimensional GPS position solution, including clock correction.

Example:

Suppose you open a navigation application and want to find your current location.

Your smartphone receives GPS signals and calculates its position.

The application displays your position on a digital map.

Advantages of GPS
  • Provides geographical positioning.

  • Useful for tracking movement.

Limitations of GPS
  • May perform poorly inside buildings.

  • Requires time to obtain a reliable position in some situations.
  • Uses battery power.
  • Accuracy can vary depending on the environment and receiver.

GPS can determine a device's position without an internet connection, but downloading online maps, traffic information, and other online services requires network connectivity. Offline maps can also be used if previously downloaded.

30.1 Introduction to Mobile Platform Constraints

Mobile devices such as smartphones and tablets are powerful, but they have certain limitations compared with desktop computers.

A mobile application cannot use unlimited processing power, memory, storage, battery, or network resources. It must work within the capabilities and rules of the mobile device and its operating system.

These limitations are called Mobile Platform Constraints.

Definition: Mobile platform constraints are the hardware, software, network, security, and resource limitations that developers must consider when developing applications for mobile devices.

For example:

  • A mobile phone has limited battery capacity.
  • An older smartphone may have less RAM.
  • A mobile screen is smaller than a computer monitor.
  • Internet connectivity may become weak or unavailable.
  • Android and iOS have different operating system rules.
  • Mobile operating systems restrict some background activities to save battery.
Simple example:

Imagine that you are developing a video-editing application.

The application needs:

  • Processing power to edit videos.
  • RAM to handle video data.
  • Storage to save edited videos.
  • Battery power to perform editing.
  • A suitable screen to display editing tools.

An older smartphone may not have enough resources to run this application smoothly.

Therefore, developers must understand mobile platform constraints before developing an application.

30.2 Why Are Mobile Platform Constraints Important?

Understanding mobile platform constraints is important because it helps developers create applications that work properly on different mobile devices.

If developers ignore these limitations, applications may become slow, consume too much battery, crash, or fail to work on certain devices.

Suppose a developer creates an application that requires 8 GB of RAM, but many users have smartphones with only 3 GB or 4 GB of RAM.

  • Slow application performance.
  • Application crashes.
  • Freezing.
  • Unexpected closing.

Developers must therefore design applications according to the resources and capabilities of their target devices.

Main reasons for considering mobile platform constraints:

  1. To improve application performance.
  2. To reduce battery consumption.
  3. To manage limited memory and storage.
  4. To support different mobile devices.
  5. To improve security and privacy.
  6. To provide a better user experience.
  7. To prevent application crashes and errors.

  • Removing unnecessary temporary files.

30.3.11 Thermal Constraints

Mobile devices generate heat when their processors, graphics processors, batteries, and other components perform intensive work.

Unlike large desktop computers, smartphones have limited space for cooling systems.

When a device becomes too hot, its operating system or hardware may reduce performance to control temperature.

Thermal throttling: This behavior is called thermal throttling.
Example:

Suppose a user plays a demanding 3D game for a long time.

The processor and GPU generate heat.

To prevent overheating, the device may reduce processing speed.

As a result:

  • Game performance may decrease.
  • Frame rates may drop.
  • Loading may become slower.

How developers handle thermal constraints:

  • Optimize application code.
  • Reduce unnecessary CPU and GPU operations.
  • Avoid continuous intensive background tasks.
  • Adjust graphics quality when needed.
  • Monitor performance under different conditions.

Image placeholder: Smartwatch, fitness band, smart glasses, and other wearable devices connected to a smartphone.

31.12.1 What is Wearable Technology?

Wearable technology refers to electronic devices that people wear on their bodies.

These devices often contain sensors and connect with mobile applications to collect and display information.

Examples include:

  • Smartwatches.
  • Fitness bands.
  • Smart glasses.
  • Health-monitoring devices.
  • Smart rings.
31.12.2 How Wearable Technology Works with Mobile Apps
  1. A wearable device collects information through its sensors.
  2. It communicates with a smartphone through Bluetooth or another supported connection.
  3. The mobile application receives the information.
  4. The application displays reports and notifications.
  5. The user can review the collected information.
31.12.3 Applications
1. Fitness Tracking

Applications display steps, distance, and activity information.

2. Health Monitoring

Supported devices can collect measurements such as heart rate.

3. Notifications

Smartwatches display calls, messages, and application alerts.

4. Navigation

Some wearable devices display navigation instructions.

5. Personal Safety

Certain devices support emergency alerts and location-sharing features.

31.12.4 Advantages
  • Provides convenient access to information.
  • Supports activity tracking.
  • Connects physical devices with mobile applications.
  • Can provide real-time notifications.
31.12.5 Limitations
  • Battery life may be limited.
  • Sensor accuracy varies.
  • Devices may have limited screen space.
  • Compatibility can vary between manufacturers.
  • Personal data requires privacy protection.

31.13 Progressive Web Applications (PWAs)

Image placeholder: A mobile browser displaying a website with an install option and an app-like home-screen icon.

31.13.1 What is a Progressive Web Application?

A Progressive Web Application (PWA) is a web application that uses modern web technologies to provide an app-like experience through a web browser.

A PWA can be installed on supported devices and may provide features such as offline access, notifications, and home-screen installation, depending on browser and operating system support.

31.13.2 How PWA Works

A PWA commonly uses three important technologies:

1. HTML

HTML provides the structure of the application.

2. CSS

CSS controls the design and appearance.

3. JavaScript

JavaScript provides functionality and interactivity.

PWAs can also use:

  • Web App Manifest: Provides information about the application, such as its name, icons, and display behavior.
  • Service Worker: A background script that can support caching, offline behavior, and certain background capabilities.
  • HTTPS: Provides secure communication and is required for many PWA capabilities.
31.13.3 Applications of PWA
  • Online shopping.
  • News applications.
  • Educational platforms.
  • Business applications.
  • Social platforms.
31.13.4 Advantages
  • Can work across multiple platforms through browsers.
  • Does not always require installation through a traditional app store.
  • Can provide offline functionality.
  • Can be updated through web deployment.
  • Reuses web-development technologies.
31.13.5 Limitations
  • Browser capabilities differ.
  • Some native device features may be unavailable or restricted.
  • Performance and functionality may differ from native applications.
  • App store distribution and discovery may require additional configuration.

31.14 How Emerging Technologies Work Together

Emerging technologies are not always used separately. Developers often combine multiple technologies to create advanced applications.

Example: Smart Healthcare Application

Imagine a healthcare application connected to a smartwatch.

It may use:

  • IoT: Connects the smartwatch with the mobile application.
  • Wearable Technology: Collects activity and supported health measurements.
  • Cloud Computing: Stores and synchronizes information.
  • AI: Analyzes collected information to identify patterns.
  • Machine Learning: Helps create predictions based on suitable training data.
  • 5G: Can support faster communication where compatible coverage is available.
  • Biometric Authentication: Helps protect access to personal information.

31.16 Short Questions and Answers

Q1. What are emerging technologies?

Emerging technologies are new or rapidly developing technologies that introduce improved capabilities and methods in mobile application development.

Q2. What is Artificial Intelligence?

Artificial Intelligence is a technology that enables computers and applications to perform tasks that normally require human intelligence.

Q3. What is Machine Learning?

Machine Learning is a branch of AI that allows computers to learn patterns from data and make predictions.

Q4. What is IoT?

The Internet of Things is a technology that connects physical devices to networks so they can collect and exchange data.

Q5. What is Augmented Reality?

Augmented Reality adds digital objects or information to a view of the real-world environment.

Q6. What is Virtual Reality?

Virtual Reality creates a computer-generated environment in which users can interact with a virtual world.

Q7. What is Cloud Computing?

Cloud computing provides computing resources and services through the internet using remote servers.

Q8. What is 5G?

5G is the fifth generation of mobile network technology, designed to provide higher potential speeds, lower latency in suitable conditions, and support for more connected devices.

Q9. What is Blockchain?

Blockchain is a distributed digital ledger that stores connected records using cryptographic techniques.

Q10. What is Biometric Authentication?

Biometric authentication verifies a user's identity using characteristics such as fingerprints, facial features, or iris patterns.

Q11. What is Edge Computing?

Edge computing processes data close to where it is generated instead of sending all data to a distant cloud server.

Q12. What is Wearable Technology?

Wearable technology includes electronic devices worn on the body, such as smartwatches and fitness trackers.

Q13. What is a Progressive Web Application?

A PWA is a web application that provides an app-like experience through modern browser technologies.

Q14. What is the difference between AR and VR?

AR adds digital content to the real world, while VR creates a completely virtual environment.

Q15. Give two examples of IoT devices.

Smartwatches and smart home cameras.

Q16. How is AI used in mobile applications?

AI is used for voice assistants, image recognition, chatbots, recommendations, and predictive features.

Q17. What is the purpose of cloud computing in mobile applications?

It provides remote storage, processing, databases, backup, and synchronization services.

Q18. What is the purpose of edge computing?

It processes information near its source to reduce communication delays and unnecessary data transmission.
