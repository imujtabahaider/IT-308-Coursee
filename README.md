# IT-308 – Mobile Application Development

## About the Project
This repository contains my Mobile Application Development course project for BS Information Technology.

The website provides organized study materials, Android programming practicals, course topics, and previous examination papers.

## Website Sections

1. **Course Outline** – Complete course topics and syllabus.
2. **Practice** – Android programming exercises and practical tasks.
3. **Programs** – Java and XML source code with detailed explanations.
4. **Past Papers** – Previous examination papers for exam preparation.
5. **References** – Learning resources and useful documentation.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Java
- XML
- Android Development
