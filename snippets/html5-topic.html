HTML5 for Mobiles

Features, PWAs and mobile web development

2.1 Introduction to HTML5

Before understanding HTML5 for mobile devices, we need to understand HTML.

HTML stands for HyperText Markup Language. It is a markup language used to create the structure of web pages. It tells a web browser how to display elements such as headings, paragraphs, images, videos, links, buttons, and forms.

HTML5 is the fifth major version of HTML. It introduced new elements, features, and APIs that make it easier to develop modern websites and mobile-friendly web applications.

In simple words: HTML5 allows developers to create websites and web applications that can work on computers, tablets, and smartphones.

Examples of HTML5-based mobile applications:

Online shopping websitesMobile banking websitesEducational web applicationsSocial media websitesOnline video platforms

2.2 What is HTML5 for Mobiles?

Definition: HTML5 for mobiles refers to the use of HTML5 technologies to develop mobile-friendly websites and web applications that can run on smartphones and tablets through mobile web browsers.

In simple words, HTML5 allows developers to create applications that users can access through a mobile browser without necessarily installing a separate application from an app store.

Example: You create an online shopping website using HTML5, CSS, and JavaScript. A user can open it on Android smartphones, iPhones, tablets and desktop computers. The website automatically adjusts its layout to the screen size when it is designed responsively.

2.3 Why is HTML5 Used for Mobile Development?

HTML5 provides features that help developers create interactive, responsive, and user-friendly web applications.

1. Cross-Platform Compatibility

HTML5 applications run on different operating systems through compatible browsers. The same website can work on Android, iOS, Windows and macOS, so developers do not need a completely separate website for every operating system.

2. Responsive Web Design

Creating websites that automatically adjust their layout according to the screen size and device.

Example: a website may display three product columns on a computer, but only one column on a mobile phone.

Technologies used: HTML5, CSS3, CSS Media Queries, flexible layouts, Flexbox and Grid.

3. Multimedia Support

HTML5 provides built-in support for audio and video. Previously, developers often needed external plugins. HTML5 introduced <audio> (adds audio) and <video> (adds video).

<video controls width="300">
    <source src="video.mp4" type="video/mp4">
</video>

This code displays a video player on a web page.

4. Offline Storage

HTML5 introduced technologies that let web applications store certain information on a user's device. For example, a shopping application can temporarily save some information so it remains available even when the internet connection is lost.

  • Local Storage: stores data in the browser with no automatic expiration.
  • Session Storage: stores data for the duration of a browser page session.
  • IndexedDB: stores larger amounts of structured data in the browser.
Note: HTML5's old Web SQL and Application Cache technologies are obsolete; modern applications generally use IndexedDB and service workers.
5. Touchscreen Support

Mobile devices mainly use touchscreens instead of a mouse and keyboard. HTML5 works with JavaScript and browser events to handle: touching buttons, tapping links, scrolling pages, selecting options, and filling forms.

6. Geolocation Support

The Geolocation API allows a website to request the user's geographical location. For example, a food delivery website can use it to help identify the user's delivery area.

navigator.geolocation.getCurrentPosition(
    function(position) {
        console.log(position.coords.latitude);
        console.log(position.coords.longitude);
    }
);

The browser normally asks the user for permission before sharing location information.

7. Better Form Support

HTML5 introduced new input types that make forms easier to use, especially on mobile devices.

<form>
    <input type="email" placeholder="Enter email">
    <input type="tel" placeholder="Phone number">
    <input type="date">
    <input type="number" placeholder="Age">
    <button type="submit">Submit</button>
</form>

These input types can display suitable mobile keyboards and built-in validation.

2. Canvas Element

The Canvas element provides an area where developers can draw graphics using JavaScript. It can be used for games, charts, animations, drawing applications and data visualization.

<canvas id="myCanvas" width="300" height="150"></canvas>

<script>
const canvas = document.getElementById("myCanvas");
const ctx = canvas.getContext("2d");

ctx.fillStyle = "blue";
ctx.fillRect(20, 20, 150, 80);
</script>

This code draws a blue rectangle inside the canvas.

3. Audio and Video Elements

HTML5 provides audio and video elements for playing multimedia content without external browser plugins.

<audio controls>
    <source src="music.mp3" type="audio/mpeg">
</audio>

<video controls width="300">
    <source src="movie.mp4" type="video/mp4">
</video>

The controls attribute displays playback controls such as play, pause, and volume.

4. Local Storage

Local Storage allows developers to save small amounts of data in the user's browser.

localStorage.setItem("username", "Ali");

let user = localStorage.getItem("username");

console.log(user);   // Output: Ali

Even after closing and reopening the browser, the stored value normally remains available until it is removed or cleared.

Mobile application example: a mobile shopping website can remember a user's preferred theme or certain settings using Local Storage.
5. Web Workers

Web Workers allow JavaScript to perform certain tasks in the background without blocking the main user interface thread.

For example, if a mobile application processes a large amount of data on the main thread, the interface may become slow or unresponsive. A Web Worker can handle suitable background calculations separately.

Benefits:

  • Keeps the interface responsive
  • Performs background processing
  • Helps handle computationally intensive tasks
6. Geolocation API

Allows a web application to request the geographical position of a user.

It can provide: latitude, longitude, accuracy, altitude (when available), speed (when available).

Example applications:

Google MapsFood delivery servicesLocation-based servicesNavigation applications
7. Drag and Drop

The Drag and Drop API allows users to move elements or files from one location to another. For example, a user can drag a file into an upload area.

Used in: file upload applications, image editors, task management applications, online design tools.

2.5 Mobile Web Applications vs Native Mobile Applications

HTML5 is commonly used to develop mobile web applications. However, mobile web applications and native applications are not exactly the same.

Mobile Web Application

Runs inside a mobile web browser. Generally developed using HTML5, CSS and JavaScript. Examples: mobile-friendly online shopping and banking websites.

Native Mobile Application

Developed specifically for a particular operating system (Android: Kotlin or Java; iOS: Swift or Objective-C). Normally installed through an app store or another supported distribution method.

Main Differences

Mobile Web ApplicationNative Mobile Application
Runs in a web browserRuns as an installed application
Uses HTML, CSS and JavaScriptUses platform-specific technologies
Usually accessed through a URLUsually installed on the device
Works across compatible browsersDeveloped for a particular platform
Device access may be limited by browser APIsCan access many native device features
Updates are usually made on the serverUpdates may require app releases

2.6 Progressive Web Applications (PWA)

A Progressive Web Application (PWA) is a web application that uses modern browser technologies to provide an experience similar to an installed mobile application. PWAs combine the accessibility of websites with several useful application-like features.

Main Features of PWA

  1. Installability: users can install supported PWAs on their devices.
  2. Offline Support: service workers can cache resources and support selected offline functionality.
  3. Responsive Design: PWAs adjust to different screen sizes.
  4. Push Notifications: supported browsers and operating systems can deliver notifications with user permission.
  5. Fast Loading: caching can improve loading speed.
  6. App-Like Experience: a PWA can open in a standalone window without the usual browser interface when installed and configured appropriately.

Main Technologies Used in PWA

  • HTML: creates the structure.
  • CSS: designs the interface.
  • JavaScript: adds functionality.
  • Service Worker: handles background tasks and caching.
  • Web App Manifest: provides application information such as name and icons.

2.7 Advantages and 2.8 Disadvantages of HTML5 for Mobile Development

Advantages
  1. Cross-Platform Compatibility: works on different operating systems through compatible browsers.
  2. Reduced Development Cost: same web technologies for different devices.
  3. Easy Maintenance: changes are deployed on the server without users installing a new native version.
  4. Multimedia Support: audio and video integrate directly into web pages.
  5. Responsive Design: adjusts to different screen sizes.
  6. Offline Capabilities: modern browser technologies allow selected offline features.
  7. Easy Learning: common web technologies, widely taught and documented.
  8. No Mandatory App Store Installation: users access ordinary mobile web apps directly through a browser.
Disadvantages
  1. Performance Limitations: demanding apps, especially graphics-intensive games, may perform better natively.
  2. Browser Dependency: depends on the browser's capabilities and compatibility.
  3. Limited Device Access: some hardware and OS features may not be available through standard web APIs.
  4. Internet Dependency: many web apps need an internet connection, although offline functionality can be implemented.
  5. Different Browser Behavior: features may behave differently across browsers and operating systems.
  6. User Experience: some web apps may not feel as smooth or integrated as native apps.
  7. Security Concerns: developers must protect stored information, validate user input, and use secure connections.
