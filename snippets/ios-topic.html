iOS: Architecture, Framework and Application Development

Apple's layers, frameworks, languages and tools

4.1 Introduction to iOS

Simple definition: iOS is Apple's mobile operating system that provides a platform for running applications and managing the hardware and software of iPhone devices.

iOS is a mobile operating system developed by Apple Inc. for its iPhone devices. It manages the hardware and software of an iPhone and provides an environment in which users can run mobile applications.

iOS controls different functions of an iPhone:

Touchscreen operationsCamera functionalityInternet connectivityMemory managementApplication executionSecurityNotificationsMultimedia operations

Examples of applications available on iOS:

WhatsAppInstagramYouTubeSafariApple MapsFaceTimeApple Music

4.2 History of iOS

  1. 2007: Apple introduced the first iPhone with an operating system initially called iPhone OS.
  2. 2008: Apple introduced the App Store, allowing users to download third-party applications.
  3. 2010: The operating system was renamed iOS.
  4. 2013: iOS 7 introduced a major redesign of the user interface.
  5. Later versions: improvements in security, performance, multitasking, widgets, and application development.
  6. Modern iOS: advanced features such as improved privacy controls, powerful frameworks, and modern development tools.

4.3 Main Features of iOS

1. User-Friendly Interface

Simple and easy to use through touch gestures, icons, buttons, menus and notifications.

2. Security

Mechanisms to protect devices and user information:

  • Application sandboxing
  • Code signing
  • Data encryption
  • Face ID and Touch ID
  • Permission controls
3. Multitasking

Users can switch between applications and perform supported background operations, for example listening to music while browsing the internet.

4. App Store

A platform where users can discover, download, and update applications.

5. Siri

Apple's virtual assistant. Users interact through voice commands to perform supported tasks.

6. iCloud Integration

Apple's cloud service to synchronize and store supported information across Apple devices: photos, contacts, documents, backups.

7. Regular Software Updates

New features, security improvements, and bug fixes.

8. Hardware and Software Integration

Apple designs both its devices and operating systems. This close integration helps optimize performance and provides a consistent user experience.

Part 1: iOS Architecture

4.4 What is iOS Architecture?

Definition: iOS Architecture is the layered structure of the iOS operating system that explains how hardware, system services, frameworks, and applications work together.

In simple words, it explains how an iPhone works internally and how different software layers communicate with each other. iOS uses four major architectural layers, and each layer provides specific services to the layer above it:

  1. Cocoa Touch Layer
  2. Media Layer
  3. Core Services Layer
  4. Core OS Layer
1. Cocoa Touch Layer

The highest layer of iOS Architecture. It provides the frameworks and technologies required to develop the user interface and handle user interactions. This layer helps developers create screens, buttons, menus, and other interactive elements.

Main responsibilities:

A. User Interface Management

Tools for creating application interfaces: buttons, text fields, navigation bars, tables, images, menus.

B. Touch Event Handling

Handles user interactions with the touchscreen: tapping, swiping, scrolling, pinching, touching buttons.

C. Application Lifecycle Management

Manages the states of an application: launching, becoming active, moving into the background, termination.

D. Notifications

Facilities for managing application notifications and user interactions with them.

Important frameworks: UIKit, SwiftUI, UserNotifications.

Example: when you open Instagram, the interface you see, including buttons, menus, and navigation elements, uses technologies provided by the higher-level iOS frameworks.
2. Media Layer

Provides technologies for handling graphics, animations, audio, and video. It helps applications display visual content and play multimedia.

  • A. Graphics: displaying images, shapes, and other visual elements.
  • B. Animation: smooth animations and visual transitions.
  • C. Audio: recording and playing audio.
  • D. Video: playing, recording, and processing video.

Important frameworks: Core Graphics, Core Animation, AVFoundation, Core Audio, Metal.

Example: when you play a video on an iPhone, the Media Layer provides technologies that help process and display it.
3. Core Services Layer

Provides essential system services used by applications: important background functionality that applications need to operate.

  • A. Data Management: storing and managing application information.
  • B. Networking: allows applications to communicate over the internet.
  • C. Location Services: geographical location information, subject to user permission.
  • D. Database Support: store and retrieve data.
  • E. Cloud Services: communicating with cloud-based services.

Important frameworks: Core Data, Core Location, Core Foundation, Foundation, CloudKit.

Example: when you use Apple Maps, Core Services technologies help the application work with location information and network data.
4. Core OS Layer

The lowest layer of iOS Architecture. It provides low-level operating system functionality and communicates with the device hardware. It handles important internal operations that allow the iPhone to function.

  • A. Memory Management: memory used by the operating system and applications.
  • B. File System Management: storing and accessing files.
  • C. Security: low-level security mechanisms, including encryption and system protection.
  • D. Process Management: execution and management of system processes.
  • E. Device Communication: low-level interfaces and drivers for hardware.
  • F. Networking: low-level networking functionality.

Important technologies: Darwin kernel, BSD components, Security, File System, Networking, Device drivers.

Example: when you save a photograph, lower-level operating system services help manage the storage and file operations.

4.5 How iOS Architecture Works: Real-Life Example

Suppose you open the Camera application on your iPhone and capture a photograph. All four layers work together:

  1. Cocoa Touch Layer: handles your interaction when you open the camera and press the capture button.
  2. Media Layer: provides image-processing and graphics-related technologies.
  3. Core Services Layer: provides supporting services such as data management.
  4. Core OS Layer: supports low-level hardware communication, device drivers, and file storage.

Result: the photograph is captured and saved on your iPhone.

The important point is that all four layers cooperate to perform a single task.

Part 2: iOS Framework

4.6 What is an iOS Framework?

Definition: An iOS Framework is a collection of pre-written code, APIs, libraries, and services that developers use to build applications for Apple devices.

Frameworks provide ready-made functionality so developers do not have to create every feature from the beginning.

Example: to use the iPhone camera you do not write all the camera hardware management code yourself. Apple provides the AVFoundation framework, which offers APIs for camera and media functionality.

4.7 Important iOS Frameworks

1. UIKit Framework
UIKit stands for User Interface Kit. It is a framework used to create and manage the user interface of iOS applications, with ready-made components for building application screens.

Main functions: creating buttons, creating text fields, displaying images, managing navigation, handling touch interactions, managing view controllers.

Example: a login application needs an email text field, a password text field, a login button and a registration link. UIKit provides components to create these elements.
2. SwiftUI Framework
SwiftUI is Apple's modern declarative framework for building user interfaces across Apple platforms. Developers describe what the interface should look like, and SwiftUI manages much of the process of updating it when data changes.

Main functions: creating application interfaces, designing buttons and forms, building navigation, creating animations, updating interfaces when data changes.

Example: a button created with SwiftUI:

import SwiftUI

struct ContentView: View {
    var body: some View {
        Button("Click Me") {
            print("Button clicked")
        }
    }
}

This code creates a button with the text "Click Me".

3. Foundation Framework

Provides essential programming features used by iOS applications.

Main functions: managing strings, working with dates and times, handling collections, managing URLs, working with files, supporting networking-related operations.

Example: a student application stores the student name, registration date, email address and course information. Foundation provides basic data types and utilities to manage this information.
4. Core Data Framework

Used to manage an application's model data. It helps developers store, retrieve, and manage structured information.

Main functions: saving application data, retrieving records, updating information, deleting records, managing relationships between data objects.

Example: a notes application can use Core Data to store note titles, descriptions, creation dates and categories.
5. Core Location Framework

Provides services for obtaining geographical location information.

Main functions: accessing location information, getting latitude and longitude, monitoring location changes, supporting location-based features.

Example: a food delivery application can use Core Location to help identify the user's delivery location. Location access requires appropriate authorization from the user.
6. AVFoundation Framework

AVFoundation stands for Audio Video Foundation. It provides technologies for working with audio and video.

Main functions: recording audio, playing audio, capturing video, playing video, accessing camera functionality, processing audiovisual media.

Example: a video recording application can use AVFoundation to access the camera and record videos.
7. Core Graphics Framework

A graphics framework used for creating and rendering two-dimensional graphics.

Main functions: drawing shapes, creating paths, rendering images, drawing text, working with colors.

Example: a drawing application can use Core Graphics to draw lines, circles, rectangles, and other shapes.
8. CloudKit Framework

Allows applications to store and synchronize data using Apple's iCloud infrastructure.

Main functions: storing data in iCloud, synchronizing supported information, managing cloud records, supporting data sharing.

Example: a notes application can use CloudKit to synchronize notes across supported Apple devices.

Part 3: iOS Application Development

4.9 What is iOS Application Development?

Definition: iOS Application Development is the process of designing, programming, testing, and deploying applications that run on Apple's iOS operating system.

In simple words, it means creating mobile applications for iPhones.

Banking applicationsEducational applicationsShopping applicationsSocial media applicationsGamesHealthcare applications

4.10 Programming Languages Used for iOS Development

1. Swift

A modern programming language developed by Apple. It is the primary language recommended for modern iOS application development.

Features of Swift:

  • Easy-to-read syntax
  • Strong type system
  • Memory safety features
  • High performance
  • Support for object-oriented and protocol-oriented programming
  • Compatibility with Apple's development frameworks
import Foundation

let name = "Muhammad"

print("Hello, \(name)")   // Output: Hello, Muhammad

This program stores a name in a constant and displays a greeting.

2. Objective-C

An object-oriented programming language historically used for Apple application development. It was widely used before Swift was introduced.

Main features: object-oriented programming, dynamic runtime, integration with Apple's frameworks, compatibility with existing iOS projects.

#import <Foundation/Foundation.h>

int main() {
    @autoreleasepool {
        NSString *name = @"Ali";

        NSLog(@"Hello, %@", name);
    }

    return 0;
}

Objective-C is still supported and is found in many existing Apple applications and codebases.

4.11 Tools Required for iOS Application Development

1. Xcode

Apple's official IDE for developing applications for Apple platforms. Tools for:

  • Writing Swift and Objective-C code
  • Designing user interfaces
  • Testing applications
  • Debugging errors
  • Running simulators
  • Building applications
2. iOS SDK

Provides the tools, APIs, libraries, and resources needed to develop iOS applications. It includes:

  • Apple frameworks
  • Development APIs
  • System libraries
  • Simulator support
  • Development resources
3. iOS Simulator

Runs and tests iOS applications on a Mac without a physical iPhone for every test.

Example: test an application on simulated iPhone devices with different screen sizes.

4. Interface Builder

A visual interface-design tool integrated into Xcode. Design interfaces visually with buttons, labels, text fields, images and navigation elements.

5. Swift Package Manager

Manages external Swift packages and dependencies.

Example: add an external library to a project instead of manually writing all its functionality.

4.12 Steps Involved in iOS Application Development

  1. Requirement Analysis: identify the purpose of the application and its required features. Example: a student management application.
  2. UI/UX Design: design application screens, buttons, navigation, and layouts.
  3. Environment Setup: install Xcode and configure the required iOS SDK and development tools.
  4. Programming: write application code using Swift or Objective-C.
  5. Framework Integration: use frameworks such as UIKit, SwiftUI, Core Data, and AVFoundation when needed.
  6. Testing and Debugging: test using the iOS Simulator and supported physical devices.
  7. Building: compile the application and prepare it for distribution.
  8. Deployment: submit to Apple's App Store review process or distribute through another supported method.
  9. Maintenance: fix bugs, improve performance, and release updates.

4.13 Important Components of an iOS Application

1. App Delegate

An application lifecycle-related component. It handles certain application-level events and responsibilities:

  • Application launch events
  • Lifecycle transitions in traditional UIKit applications
  • Application-level configuration
2. Scene Delegate

Manages the lifecycle and behavior of an individual application scene in UIKit-based applications that use the scene lifecycle. A scene generally represents an instance of an application's user interface.

3. View Controller

Manages a screen or part of an application's user interface in UIKit.

Example: a shopping app may have Login, Home, Product and Payment view controllers.

4. Model

Represents the application's data and business logic.

Example: a Student Model containing student ID, name, email and course.

5. View

Represents the user interface displayed to the user: buttons, text fields, images, labels, tables.

6. Controller

In the traditional Model-View-Controller (MVC) pattern, the Controller coordinates interactions between the Model and the View.

Example: when a user presses a login button, the controller processes the input and communicates with the model or authentication service.

4.14 Advantages and 4.15 Disadvantages of iOS

Advantages
  1. Strong Security: application sandboxing, encryption, and code signing.
  2. User-Friendly Interface: a simple and consistent user experience.
  3. High Performance: hardware and software integration helps optimize performance.
  4. Regular Updates: security improvements and new features.
  5. Quality Control: the App Store review process helps enforce quality and security requirements.
  6. Excellent Hardware Integration: apps can use Apple hardware features through supported frameworks and APIs.
  7. Developer Support: Xcode, SDKs, documentation, and frameworks.
  8. Privacy Protection: permission controls for location, camera, microphone, and contacts.
Disadvantages
  1. Limited Device Support: designed primarily for Apple's iPhone hardware.
  2. Development Cost: generally requires access to a Mac and Apple's development tools.
  3. Strict App Store Policies: apps must follow Apple's distribution and review requirements.
  4. Limited Customization: less freedom to customize certain system-level features compared with Android.
  5. Closed Ecosystem: unlike AOSP, iOS is not an open-source operating system.
  6. Development Learning Curve: developers need to learn Swift or Objective-C and Apple's frameworks.
  7. Hardware Restrictions: less freedom to modify or directly control certain hardware and system-level functions.
