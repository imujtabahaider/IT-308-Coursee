2. Registration Form with Main Views

This application creates a Student Registration Form using different Android UI components, including TextView, EditText, RadioGroup, RadioButton, Spinner, CheckBox and Button. The user enters personal information, selects a gender and course, accepts the terms and conditions, and clicks the Register button. The application validates the entered information and displays a Toast message.

MainActivity.java

package com.example.registrationform;

import android.os.Bundle;
import android.widget.*;
import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    EditText etName, etEmail, etPassword;
    RadioGroup rgGender;
    Spinner spCourse;
    CheckBox cbTerms;
    Button btnRegister;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        etName = findViewById(R.id.etName);
        etEmail = findViewById(R.id.etEmail);
        etPassword = findViewById(R.id.etPassword);
        rgGender = findViewById(R.id.rgGender);
        spCourse = findViewById(R.id.spCourse);
        cbTerms = findViewById(R.id.cbTerms);
        btnRegister = findViewById(R.id.btnRegister);

        String[] courses = {
            "Select Course",
            "BS Information Technology",
            "BS Computer Science",
            "BS Software Engineering"
        };

        ArrayAdapter<String> adapter = new ArrayAdapter<>(
            this,
            android.R.layout.simple_spinner_item,
            courses
        );

        adapter.setDropDownViewResource(
            android.R.layout.simple_spinner_dropdown_item
        );

        spCourse.setAdapter(adapter);

        btnRegister.setOnClickListener(v -> {

            String name = etName.getText().toString();
            String email = etEmail.getText().toString();
            String password = etPassword.getText().toString();

            int selectedId = rgGender.getCheckedRadioButtonId();

            if (name.isEmpty() || email.isEmpty() || password.isEmpty()) {
                Toast.makeText(this, "Please fill all fields",
                    Toast.LENGTH_SHORT).show();
                return;
            }

            if (selectedId == -1) {
                Toast.makeText(this, "Please select gender",
                    Toast.LENGTH_SHORT).show();
                return;
            }

            if (spCourse.getSelectedItemPosition() == 0) {
                Toast.makeText(this, "Please select a course",
                    Toast.LENGTH_SHORT).show();
                return;
            }

            if (!cbTerms.isChecked()) {
                Toast.makeText(this, "Please accept terms and conditions",
                    Toast.LENGTH_SHORT).show();
                return;
            }

            RadioButton selectedGender = findViewById(selectedId);

            String gender = selectedGender.getText().toString();
            String course = spCourse.getSelectedItem().toString();

            Toast.makeText(this,
                "Registration Successful!",
                Toast.LENGTH_LONG).show();
        });
    }
}

Program 3: Two Screens with Fragments

This program demonstrates how to create two different screens using Android Fragments. The user can switch between the First Screen and Second Screen by clicking the buttons in the main Activity.

1. Java Code

MainActivity.java

package com.example.fragmentsapp;

import android.os.Bundle;
import android.widget.Button;

import androidx.appcompat.app.AppCompatActivity;
import androidx.fragment.app.Fragment;

public class MainActivity extends AppCompatActivity {

    Button btnFirst, btnSecond;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        btnFirst = findViewById(R.id.btnFirst);
        btnSecond = findViewById(R.id.btnSecond);

        if (savedInstanceState == null) {
            loadFragment(new FirstFragment());
        }

        btnFirst.setOnClickListener(v -> {
            loadFragment(new FirstFragment());
        });

        btnSecond.setOnClickListener(v -> {
            loadFragment(new SecondFragment());
        });
    }

    private void loadFragment(Fragment fragment) {

        getSupportFragmentManager()
                .beginTransaction()
                .replace(R.id.fragmentContainer, fragment)
                .commit();
    }
}

Understanding MainActivity.java

  1. package com.example.fragmentsapp; — Defines the package name of the application. It identifies the location of the Java classes in the project.
  2. import android.os.Bundle; — Imports the Bundle class, which stores information about the Activity's state.
  3. import android.widget.Button; — Imports the Button class so that buttons can be used in Java.
  4. import androidx.appcompat.app.AppCompatActivity; — Imports AppCompatActivity, the base class used to create this Activity.
  5. import androidx.fragment.app.Fragment; — Imports the Fragment class so that fragments can be managed in the Activity.
  6. public class MainActivity extends AppCompatActivity — Creates the MainActivity class and inherits the features of AppCompatActivity.
  7. Button btnFirst, btnSecond; — Declares two Button variables. They will refer to the First Screen and Second Screen buttons in the XML layout.
  8. @Override — Indicates that the following method overrides a method provided by the parent class.
  9. protected void onCreate(Bundle savedInstanceState) — The onCreate() method runs when the Activity is created. It is used to initialize the screen and its components.
  10. super.onCreate(savedInstanceState); — Calls the parent class's onCreate() method to perform the required Activity initialization.
  11. setContentView(R.layout.activity_main); — Connects MainActivity with the activity_main.xml layout file.
  12. btnFirst = findViewById(R.id.btnFirst); — Finds the First Screen button from the XML layout and connects it to the btnFirst variable.
  13. btnSecond = findViewById(R.id.btnSecond); — Finds the Second Screen button and connects it to the btnSecond variable.
  14. if (savedInstanceState == null) — Checks whether the Activity is being created for the first time. A null value means there is no previously saved Activity state.
  15. loadFragment(new FirstFragment()); — Loads the FirstFragment when the Activity is initially opened.
  16. btnFirst.setOnClickListener(...) — Sets a click listener on the First Screen button. The code inside it runs when the user clicks that button.
  17. loadFragment(new FirstFragment()); — Creates and displays a new FirstFragment when the First Screen button is clicked.
  18. btnSecond.setOnClickListener(...) — Sets a click listener on the Second Screen button.
  19. loadFragment(new SecondFragment()); — Creates and displays a new SecondFragment when the Second Screen button is clicked.
  20. private void loadFragment(Fragment fragment) — Defines a private method that accepts a Fragment object. This method is responsible for displaying the selected fragment.
  21. getSupportFragmentManager() — Gets the FragmentManager, which manages fragments inside the Activity.
  22. .beginTransaction() — Starts a FragmentTransaction. A transaction is a group of operations used to add, remove, or replace fragments.
  23. .replace(R.id.fragmentContainer, fragment) — Replaces the current fragment inside the FrameLayout named fragmentContainer with the fragment passed to the method.
  24. .commit(); — Submits the fragment transaction so Android can perform the replacement.

Program 7: Remember Name and Email with Save and Clear (SharedPreferences)

This Android application demonstrates how to store and retrieve user information using SharedPreferences. The user enters a name and email address and clicks the Save button to store the information. Even after closing and reopening the application, the saved information appears automatically. The Clear button removes the saved information and empties both input fields.

1. Java Code

MainActivity.java

package com.example.sharedpreferencesapp;

import android.os.Bundle;
import android.content.SharedPreferences;
import android.widget.Button;
import android.widget.EditText;
import android.widget.Toast;

import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {

    EditText etName, etEmail;
    Button btnSave, btnClear;

    SharedPreferences sharedPreferences;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        etName = findViewById(R.id.etName);
        etEmail = findViewById(R.id.etEmail);
        btnSave = findViewById(R.id.btnSave);
        btnClear = findViewById(R.id.btnClear);

        sharedPreferences = getSharedPreferences(
            "UserData", MODE_PRIVATE
        );

        loadData();

        btnSave.setOnClickListener(v -> {
            saveData();
        });

        btnClear.setOnClickListener(v -> {
            clearData();
        });
    }

    private void saveData() {

        String name = etName.getText().toString();
        String email = etEmail.getText().toString();

        SharedPreferences.Editor editor =
            sharedPreferences.edit();

        editor.putString("name", name);
        editor.putString("email", email);

        editor.apply();

        Toast.makeText(this,
            "Data Saved Successfully",
            Toast.LENGTH_SHORT).show();
    }

    private void loadData() {

        String name = sharedPreferences.getString("name", "");
        String email = sharedPreferences.getString("email", "");

        etName.setText(name);
        etEmail.setText(email);
    }

    private void clearData() {

        SharedPreferences.Editor editor =
            sharedPreferences.edit();

        editor.clear();
        editor.apply();

        etName.setText("");
        etEmail.setText("");

        Toast.makeText(this,
            "Data Cleared Successfully",
            Toast.LENGTH_SHORT).show();
    }
}

Program 10: Open a Second Activity and Pass Data (Explicit Intent)

This Android application demonstrates how to open a second Activity from the main Activity using an Explicit Intent. The user enters a student's name and email address on the first screen and clicks Submit. The application transfers both values to the second Activity, where they are displayed using TextViews.

import android.os.Bundle;
import android.content.Intent;
import android.widget.Button;
import android.widget.EditText;

public class MainActivity extends AppCompatActivity {

    EditText etName, etEmail;
    Button btnSubmit;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        etName = findViewById(R.id.etName);
        etEmail = findViewById(R.id.etEmail);

3. AndroidManifest.xml Configuration

Both Activities must be registered in AndroidManifest.xml. MainActivity is the launcher Activity, while SecondActivity is the destination Activity opened by the Explicit Intent. 

<application
    ... >

    <activity
        android:name=".SecondActivity"
        android:exported="false" />

    <activity
        android:name=".MainActivity"
        android:exported="true">

        <intent-filter>
            <action android:name="android.intent.action.MAIN" />
            <category android:name="android.intent.category.LAUNCHER" />
        </intent-filter>

    </activity>

</application>

Understanding AndroidManifest.xml

  1. <application> — Contains the configuration and declarations for the application.
  2. <activity android:name=".SecondActivity"> — Registers SecondActivity so Android knows that the application contains this screen.
  3. android:exported="false" — Prevents other applications from launching SecondActivity directly. The application itself can still open it.
  4. <activity android:name=".MainActivity"> — Registers MainActivity as an Activity in the application.
  5. android:exported="true" — Allows the system launcher to start MainActivity because it has a launcher intent filter.
  6. <intent-filter> — Declares the types of Intent that can launch MainActivity.
  7. android.intent.action.MAIN — Identifies MainActivity as the main entry point of the application.
  8. android.intent.category.LAUNCHER — Makes MainActivity available as the application's launch screen from the device launcher.

Note: The three dots in the application opening tag represent other existing manifest attributes. Do not paste the dots literally. Add the two Activity declarations inside your existing application element. If Android Studio has already registered MainActivity, avoid adding it twice.

5. Important Concepts Used

  • Activity: An Android application component that represents a screen with a user interface.
  • Intent: An object used to request an action from another Android component.
  • Explicit Intent: An Intent that identifies a specific destination component, such as SecondActivity.
  • putExtra(): Adds data to an Intent using a key-value pair.
  • getIntent(): Retrieves the Intent that started the current Activity.
  • getStringExtra(): Retrieves a String value from an Intent using its key.
  • startActivity(): Starts another Activity using the supplied Intent.
  • TextView: Displays the received information on the second screen.

6. Project Files Required

  • Java: MainActivity.java, SecondActivity.java
  • res/layout: activity_main.xml, activity_second.xml
  • Manifest: AndroidManifest.xml

Important: The keys used with putExtra() and getStringExtra() must match exactly. For example, student_name must be used when both sending and receiving the name. This program transfers data between Activities within the same application; it does not save the information permanently.
