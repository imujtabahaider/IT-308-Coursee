Q.2: Short Questions 4 × 6 = 24 marks

i.

What is SharedPreferences in Android, and how can it be used to store persistent data?

Show solution

SharedPreferences stores small key-value data. Use an Editor to save and apply() to write the change; read it back with the matching get method and a default value.

SharedPreferences prefs =
    getSharedPreferences("MyPrefs", MODE_PRIVATE);

// Store a String value
SharedPreferences.Editor editor = prefs.edit();
editor.putString("username", "Muhammad");
editor.apply();

// Retrieve the value
String username = prefs.getString("username", "Guest");

Topic: User Preferences


ii.

Explain the difference between Implicit Intent and Explicit Intent in Android app development.

Show solution

Explicit Intent: names the exact component to start, usually inside the same app. Implicit Intent: describes an action, and Android finds an app that can do it.

// Explicit Intent: open ProfileActivity in the same app
Intent intent = new Intent(MainActivity.this, ProfileActivity.class);
startActivity(intent);

// Implicit Intent: open a website in any browser
Intent web = new Intent(
    Intent.ACTION_VIEW,
    Uri.parse("https://www.google.com")
);
startActivity(web);

ii.

Write code to open a new Activity using an Intent and pass a String value from one Activity to another.

Show solution

Use an explicit Intent and send data with putExtra().

MainActivity (sender):

Intent intent = new Intent(MainActivity.this, DetailActivity.class);
intent.putExtra("name", "Muhammad");
intent.putExtra("age", 22);
startActivity(intent);

DetailActivity (receiver), inside onCreate():

String name = getIntent().getStringExtra("name");
int age = getIntent().getIntExtra("age", 0);

DetailActivity must also be declared in AndroidManifest.xml.

iii.

Write code to check if the device has an active Internet connection and display a Toast based on the result.

Show solution

Add this permission to the manifest, then check the network with ConnectivityManager.

<uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
ConnectivityManager cm =
    (ConnectivityManager) getSystemService(Context.CONNECTIVITY_SERVICE);

Network network = cm.getActiveNetwork();
NetworkCapabilities caps = cm.getNetworkCapabilities(network);

boolean connected = caps != null
    && caps.hasCapability(NetworkCapabilities.NET_CAPABILITY_INTERNET)
    && caps.hasCapability(NetworkCapabilities.NET_CAPABILITY_VALIDATED);

if (connected) {
    Toast.makeText(this, "Internet is available", Toast.LENGTH_SHORT).show();
} else {
    Toast.makeText(this, "No internet connection", Toast.LENGTH_SHORT).show();
}

v.

Write code to programmatically play an audio file from a URI, using MediaPlayer in Android.

Show solution 
MediaPlayer mediaPlayer = new MediaPlayer();
Uri uri = Uri.parse("https://example.com/audio.mp3");

try {
    mediaPlayer.setAudioAttributes(
        new AudioAttributes.Builder()
            .setContentType(AudioAttributes.CONTENT_TYPE_MUSIC)
            .setUsage(AudioAttributes.USAGE_MEDIA)
            .build());

    mediaPlayer.setDataSource(this, uri);
    mediaPlayer.setOnPreparedListener(mp -> mp.start());
    mediaPlayer.prepareAsync();

} catch (IOException e) {
    e.printStackTrace();
}

// Release it when the Activity is destroyed
@Override
protected void onDestroy() {
    super.onDestroy();
    mediaPlayer.release();
}

prepareAsync() prepares the audio without freezing the UI, and the prepared listener starts playback. A web address needs the INTERNET permission.

i. 8

Write down Java code to do following: You have to create three activities named LoginActivity, AdminActivity, and OperatorActivity. On LoginActivity there should be two text boxes to enter username and password. If user enters username “admin” and password “123” it should go to AdminActivity. On the other hand, if user enters username “operator” and password “abc” it should launch OperatorActivity. Also check in code that if the user does not enter username or password, then show an error message to the user that input is required.

Show solution

Login layout (activity_login.xml):

<LinearLayout
    xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical"
    android:padding="20dp">

    <EditText
        android:id="@+id/edtUsername"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:hint="Username" />

    <EditText
        android:id="@+id/edtPassword"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:hint="Password"
        android:inputType="textPassword" />

    <Button
        android:id="@+id/btnLogin"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:text="Login" />

</LinearLayout>

LoginActivity.java:

public class LoginActivity extends AppCompatActivity {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_login);

        EditText edtUsername = findViewById(R.id.edtUsername);
        EditText edtPassword = findViewById(R.id.edtPassword);
        Button btnLogin = findViewById(R.id.btnLogin);

        btnLogin.setOnClickListener(v -> {

            String username = edtUsername.getText().toString().trim();
            String password = edtPassword.getText().toString().trim();

            if (username.isEmpty() || password.isEmpty()) {

                Toast.makeText(this,
                    "Username and password are required",
                    Toast.LENGTH_SHORT).show();

            } else if (username.equals("admin") && password.equals("123")) {

                startActivity(new Intent(this, AdminActivity.class));

            } else if (username.equals("operator") && password.equals("abc")) {

                startActivity(new Intent(this, OperatorActivity.class));

            } else {

                Toast.makeText(this,
                    "Invalid username or password",
                    Toast.LENGTH_SHORT).show();
            }
        });
    }
}

AdminActivity and OperatorActivity are two more Activities, each with its own layout (for example a TextView saying "Admin" or "Operator"). All three Activities must be declared in AndroidManifest.xml.

ii. 8

What are Web APIs? What is their role in Android apps? Write Java code to send request to a Web API. Assuming that an API returns a response in JSON format, write code to handle the JSON response and display data from API response on the screen in a TextView.

Show solution

Web API: a service on a server that apps call over HTTP to get or send data, usually as JSON. Role in Android apps: it lets the app use live data (users, weather, products) without storing everything on the phone.

Request the API on a background thread, parse the JSON, and show it in a TextView on the main thread:

ExecutorService executor = Executors.newSingleThreadExecutor();
Handler handler = new Handler(Looper.getMainLooper());

executor.execute(() -> {
    String text;
    try {
        URL url = new URL("https://jsonplaceholder.typicode.com/users/1");
        HttpURLConnection conn = (HttpURLConnection) url.openConnection();
        conn.setRequestMethod("GET");

        BufferedReader reader = new BufferedReader(
            new InputStreamReader(conn.getInputStream()));
        StringBuilder sb = new StringBuilder();
        String line;
        while ((line = reader.readLine()) != null) {
            sb.append(line);
        }
        reader.close();

        // Handle the JSON response
        JSONObject json = new JSONObject(sb.toString());
        String name = json.getString("name");
        String email = json.getString("email");
        text = "Name: " + name + "\nEmail: " + email;

    } catch (Exception e) {
        text = "Error loading data";
    }

    String finalText = text;
    handler.post(() -> txtResult.setText(finalText));
});

The API returns JSON such as {"name": "...", "email": "..."}. Remember the INTERNET permission in the manifest.
