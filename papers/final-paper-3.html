Q.3 24

Write code to do the following tasks in an Android app:


i. 8

Display any message in a toast for long duration.

Show solution

A Toast shows a small temporary message. Toast.LENGTH_LONG keeps it on the screen longer than Toast.LENGTH_SHORT.

Toast.makeText(
    MainActivity.this,
    "Welcome to my application",
    Toast.LENGTH_LONG
).show();

Topic: Listening for UI NotificationsTopic: Components of a Screen


ii. 8

Show Alert Dialog with title, message and 1 button.

Show solution

Use AlertDialog.Builder to set the title, the message and one button. Passing null to the button means no action on click.

new AlertDialog.Builder(this)
    .setTitle("Alert")
    .setMessage("This is an alert dialog message.")
    .setPositiveButton("OK", null)
    .show();

Import androidx.appcompat.app.AlertDialog.

Topic: Creating the User Interface


iii. 8

Store a String value in SharedPreferences and retrieve the value as well.

Show solution

SharedPreferences stores small key-value data. Use an Editor to save and apply() to write the change; read it back with the matching get method and a default value.

SharedPreferences prefs =
    getSharedPreferences("MyPrefs", MODE_PRIVATE);

// Store a String value
SharedPreferences.Editor editor = prefs.edit();
editor.putString("username", "Muhammad");
editor.apply();

// Retrieve the value
String username = prefs.getString("username", "Guest");

Topic: User Preferences


iv. 8

Write Java code to get current location of the device. Mention required permissions.

Show solution

Required permissions (AndroidManifest.xml). On Android 6.0 and later, the app must also ask the user at runtime.

<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />

Gradle dependency (Google Play services location):

implementation 'com.google.android.gms:play-services-location:21.0.1'

Java code:

FusedLocationProviderClient client =
    LocationServices.getFusedLocationProviderClient(this);

if (ActivityCompat.checkSelfPermission(this,
        Manifest.permission.ACCESS_FINE_LOCATION)
        != PackageManager.PERMISSION_GRANTED) {

    ActivityCompat.requestPermissions(this,
        new String[]{Manifest.permission.ACCESS_FINE_LOCATION}, 1);
    return;
}

client.getLastLocation().addOnSuccessListener(location -> {
    if (location != null) {
        double latitude = location.getLatitude();
        double longitude = location.getLongitude();
        Toast.makeText(this,
            "Lat: " + latitude + ", Lng: " + longitude,
            Toast.LENGTH_LONG).show();
    }
});

The code checks the permission first, asks for it if needed, and then reads the last known location. The location can be null if the device has no recent location.

v. 8

Start DetailActivity from MainActivity and pass along some dummy data.

Show solution

Use an explicit Intent and send data with putExtra().

MainActivity (sender):

Intent intent = new Intent(MainActivity.this, DetailActivity.class);
intent.putExtra("name", "Muhammad");
intent.putExtra("age", 22);
startActivity(intent);

DetailActivity (receiver), inside onCreate():

String name = getIntent().getStringExtra("name");
int age = getIntent().getIntExtra("age", 0);

DetailActivity must also be declared in AndroidManifest.xml.

Topic: Sharing Data


vi. 8

Create an options menu in XML to show a single item menu on the Toolbar.

Show solution

Menu file: res/menu/main_menu.xml with a single item.

<menu xmlns:android="http://schemas.android.com/apk/res/android"
    xmlns:app="http://schemas.android.com/apk/res-auto">

    <item
        android:id="@+id/action_settings"
        android:title="Settings"
        app:showAsAction="ifRoom" />

</menu>

Toolbar in the activity layout:

<androidx.appcompat.widget.Toolbar
    android:id="@+id/toolbar"
    android:layout_width="match_parent"
    android:layout_height="?attr/actionBarSize" />

Java: set the Toolbar as the action bar, then inflate the menu.

// in onCreate()
Toolbar toolbar = findViewById(R.id.toolbar);
setSupportActionBar(toolbar);

@Override
public boolean onCreateOptionsMenu(Menu menu) {
    getMenuInflater().inflate(R.menu.main_menu, menu);
    return true;
}

@Override
public boolean onOptionsItemSelected(MenuItem item) {
    if (item.getItemId() == R.id.action_settings) {
        Toast.makeText(this, "Settings clicked", Toast.LENGTH_SHORT).show();
        return true;
    }
    return super.onOptionsItemSelected(item);
}

Topic: Utilizing the Action Bar


vii. 8

Parse/Convert JSON object to a Java Object.

Show solution

Create a Java class that matches the JSON, then read each field from a JSONObject.

// JSON: {"id": 1, "name": "Ali", "marks": 85}

public class Student {
    int id;
    String name;
    int marks;

    Student(int id, String name, int marks) {
        this.id = id;
        this.name = name;
        this.marks = marks;
    }
}

String json = "{\"id\":1,\"name\":\"Ali\",\"marks\":85}";

try {
    JSONObject obj = new JSONObject(json);

    Student student = new Student(
        obj.getInt("id"),
        obj.getString("name"),
        obj.getInt("marks")
    );

} catch (JSONException e) {
    e.printStackTrace();
}

Alternative with the Gson library (one line, needs the Gson dependency): Student student = new Gson().fromJson(json, Student.class);

viii. 8

XML code to create drawable for background of a button that should look like this: a “GET DATA” button with a rounded border.

Show solution

The button in the picture is a white rounded rectangle with a dark border and bold text. Create res/drawable/get_data_button.xml:

<shape xmlns:android="http://schemas.android.com/apk/res/android"
    android:shape="rectangle">

    <solid android:color="#FFFFFF" />
    <stroke android:width="2dp" android:color="#000000" />
    <corners android:radius="10dp" />

</shape>

Use it as the button background:

<Button
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="GET DATA"
    android:textStyle="bold"
    android:textColor="#000000"
    android:backgroundTint="@null"
    android:background="@drawable/get_data_button" />
