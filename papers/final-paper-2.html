Write code to show Alert Dialog with title, message and 1 button. (No action is required on button click).

Show solution

Use AlertDialog.Builder to set the title, the message and one button. Passing null to the button means no action on click.

new AlertDialog.Builder(this)
    .setTitle("Alert")
    .setMessage("This is an alert dialog message.")
    .setPositiveButton("OK", null)
    .show();

Import androidx.appcompat.app.AlertDialog.

4. 5

Write code to create a Button with an icon on left side and button text: “Continue”. Add some padding, margin and border to the button.

Show solution

Button in activity_main.xml. drawableLeft puts the icon on the left, padding is inside space, layout_margin is outside space, and the border comes from a drawable.

<Button
    android:id="@+id/btnContinue"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="Continue"
    android:textColor="#14213D"
    android:drawableLeft="@drawable/ic_arrow"
    android:drawablePadding="8dp"
    android:padding="12dp"
    android:layout_margin="16dp"
    android:backgroundTint="@null"
    android:background="@drawable/button_border" />

Border drawable: res/drawable/button_border.xml

<shape xmlns:android="http://schemas.android.com/apk/res/android"
    android:shape="rectangle">

    <solid android:color="#FFFFFF" />
    <stroke android:width="2dp" android:color="#14213D" />

</shape>

ic_arrow is any icon you add to the drawable folder. backgroundTint="@null" lets a Material theme use the custom background.

5. User Data Storage 10

Design and implement a mobile application screen that allows the user to enter their name and email address, with Save and Clear buttons and an area to display saved information.

  • When Save is pressed, store the entered data locally on the device (using Shared Preferences) so it remains available after the app restarts.
  • When the app restarts, automatically retrieve and display the saved data.
  • When Clear is pressed, remove the stored data and confirm the action to the user.
Show solution

Layout (activity_main.xml): two input fields, Save and Clear buttons, and a TextView for the saved information.

<LinearLayout
    xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical"
    android:padding="20dp">

    <EditText
        android:id="@+id/edtName"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:hint="Enter name" />

    <EditText
        android:id="@+id/edtEmail"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:hint="Enter email"
        android:inputType="textEmailAddress" />

    <Button
        android:id="@+id/btnSave"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:text="Save" />

    <Button
        android:id="@+id/btnClear"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:text="Clear" />

    <TextView
        android:id="@+id/txtSaved"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:layout_marginTop="16dp"
        android:textSize="18sp" />

</LinearLayout>

Java (MainActivity.java):

public class MainActivity extends AppCompatActivity {

    EditText edtName, edtEmail;
    Button btnSave, btnClear;
    TextView txtSaved;
    SharedPreferences prefs;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        edtName = findViewById(R.id.edtName);
        edtEmail = findViewById(R.id.edtEmail);
        btnSave = findViewById(R.id.btnSave);
        btnClear = findViewById(R.id.btnClear);
        txtSaved = findViewById(R.id.txtSaved);

        prefs = getSharedPreferences("UserData", MODE_PRIVATE);

        // When the app restarts, show the saved data
        showSavedData();

        btnSave.setOnClickListener(v -> {
            SharedPreferences.Editor editor = prefs.edit();
            editor.putString("name", edtName.getText().toString());
            editor.putString("email", edtEmail.getText().toString());
            editor.apply();
            showSavedData();
            Toast.makeText(this, "Data saved", Toast.LENGTH_SHORT).show();
        });

        btnClear.setOnClickListener(v -> {
            prefs.edit().clear().apply();
            edtName.setText("");
            edtEmail.setText("");
            showSavedData();
            Toast.makeText(this, "Saved data cleared", Toast.LENGTH_SHORT).show();
        });
    }

    private void showSavedData() {
        String name = prefs.getString("name", "");
        String email = prefs.getString("email", "");

        if (name.isEmpty() && email.isEmpty()) {
            txtSaved.setText("No saved data");
        } else {
            txtSaved.setText("Name: " + name + "\nEmail: " + email);
        }
    }
}

Save stores both values, the restart shows them again through showSavedData(), and Clear removes everything and confirms with a Toast.

6. Data Fetch and Display 10

Write code for retrieving data from a remote API and showing it in a scrollable list. Include:

  • Loading indicator
  • Error handling
  • UI update once data is fetched
Show solution

Steps: show a ProgressBar, fetch the JSON on a background thread, then update a scrollable list on the main thread. If anything fails, show an error message.

Manifest: the app needs internet permission.

<uses-permission android:name="android.permission.INTERNET" />

Layout (activity_main.xml):

<LinearLayout
    xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical">

    <ProgressBar
        android:id="@+id/progressBar"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:layout_gravity="center" />

    <TextView
        android:id="@+id/txtError"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:visibility="gone" />

    <ListView
        android:id="@+id/listView"
        android:layout_width="match_parent"
        android:layout_height="match_parent" />

</LinearLayout>

Java (MainActivity.java):

public class MainActivity extends AppCompatActivity {

    ListView listView;
    ProgressBar progressBar;
    TextView txtError;
    ArrayList<String> items = new ArrayList<>();
    ArrayAdapter<String> adapter;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        listView = findViewById(R.id.listView);
        progressBar = findViewById(R.id.progressBar);
        txtError = findViewById(R.id.txtError);

        adapter = new ArrayAdapter<>(
            this, android.R.layout.simple_list_item_1, items);
        listView.setAdapter(adapter);

        loadData();
    }

    private void loadData() {
        progressBar.setVisibility(View.VISIBLE);
        txtError.setVisibility(View.GONE);

        ExecutorService executor = Executors.newSingleThreadExecutor();
        Handler handler = new Handler(Looper.getMainLooper());

        executor.execute(() -> {
            try {
                URL url = new URL("https://jsonplaceholder.typicode.com/users");
                HttpURLConnection conn = (HttpURLConnection) url.openConnection();
                conn.setRequestMethod("GET");
                conn.setConnectTimeout(10000);
                conn.setReadTimeout(10000);

                BufferedReader reader = new BufferedReader(
                    new InputStreamReader(conn.getInputStream()));
                StringBuilder sb = new StringBuilder();
                String line;
                while ((line = reader.readLine()) != null) {
                    sb.append(line);
                }
                reader.close();

                JSONArray array = new JSONArray(sb.toString());
                ArrayList<String> result = new ArrayList<>();
                for (int i = 0; i < array.length(); i++) {
                    result.add(array.getJSONObject(i).getString("name"));
                }

                // Back on the main thread: update the UI
                handler.post(() -> {
                    progressBar.setVisibility(View.GONE);
                    items.clear();
                    items.addAll(result);
                    adapter.notifyDataSetChanged();
                });

            } catch (Exception e) {
                handler.post(() -> {
                    progressBar.setVisibility(View.GONE);
                    txtError.setText("Error: could not load data");
                    txtError.setVisibility(View.VISIBLE);
                });
            }
        });
    }
}
