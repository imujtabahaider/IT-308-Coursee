ii.

Briefly describe implicit and explicit intent with the help of code examples.

Show solution

Explicit Intent: names the exact component to start, usually inside the same app. Implicit Intent: describes an action, and Android finds an app that can do it.

// Explicit Intent: open ProfileActivity in the same app
Intent intent = new Intent(MainActivity.this, ProfileActivity.class);
startActivity(intent);

// Implicit Intent: open a website in any browser
Intent web = new Intent(
    Intent.ACTION_VIEW,
    Uri.parse("https://www.google.com")
);
startActivity(web);
