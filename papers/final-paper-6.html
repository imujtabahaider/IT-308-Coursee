Q.2: Short Questions 2 × 8

i.

What do you know about notifications?

Show solution

A notification is a message an app shows outside its normal screen, in the notification drawer and status bar. Since Android 8.0 it needs a notification channel; on Android 13 and later the user must also allow POST_NOTIFICATIONS.

// 1. Create a channel (Android 8.0+)
if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.O) {
    NotificationChannel channel = new NotificationChannel(
        "student_channel",
        "Student Notifications",
        NotificationManager.IMPORTANCE_DEFAULT);

    getSystemService(NotificationManager.class)
        .createNotificationChannel(channel);
}

// 2. Build the notification
NotificationCompat.Builder builder =
    new NotificationCompat.Builder(this, "student_channel")
        .setSmallIcon(R.drawable.ic_notification)
        .setContentTitle("Assignment Reminder")
        .setContentText("Submit your assignment tomorrow.")
        .setAutoCancel(true);

// 3. Show it
NotificationManagerCompat.from(this).notify(1, builder.build());

iii.

What is Intent? Briefly describe its types.

Show solution

Explicit Intent: names the exact component to start, usually inside the same app. Implicit Intent: describes an action, and Android finds an app that can do it.

// Explicit Intent: open ProfileActivity in the same app
Intent intent = new Intent(MainActivity.this, ProfileActivity.class);
startActivity(intent);

// Implicit Intent: open a website in any browser
Intent web = new Intent(
    Intent.ACTION_VIEW,
    Uri.parse("https://www.google.com")
);
startActivity(web);

v.

How super and this are used in Java?

Show solution

this refers to the current object. super refers to the parent class, to call its constructor or its methods.

class Person {
    String name;

    Person(String name) {
        this.name = name;          // this: current object's field
    }

    void show() {
        System.out.println("Person: " + name);
    }
}

class Student extends Person {
    int marks;

    Student(String name, int marks) {
        super(name);               // super: parent constructor
        this.marks = marks;
    }

    @Override
    void show() {
        super.show();              // super: parent method
        System.out.println("Marks: " + marks);
    }
}

vi.

How can we access GUI widgets from Java code, give example?

Show solution

Give each widget an android:id in the XML, then find it in Java with findViewById() after setContentView().

// XML:  <TextView android:id="@+id/txtTitle" ... />
//       <EditText android:id="@+id/edtName" ... />
//       <Button   android:id="@+id/btnShow" ... />

TextView txtTitle = findViewById(R.id.txtTitle);
EditText edtName = findViewById(R.id.edtName);
Button btnShow = findViewById(R.id.btnShow);

btnShow.setOnClickListener(v -> {
    String name = edtName.getText().toString();
    txtTitle.setText("Hello " + name);
});

viii.

How and email is sent from android programmatically?

Show solution

Use ACTION_SENDTO with a mailto: address so only email apps respond.

Intent intent = new Intent(Intent.ACTION_SENDTO);
intent.setData(Uri.parse("mailto:student@example.com"));
intent.putExtra(Intent.EXTRA_SUBJECT, "Examination Result");
intent.putExtra(Intent.EXTRA_TEXT, "Please find my examination result.");

try {
    startActivity(intent);
} catch (ActivityNotFoundException e) {
    Toast.makeText(this, "No email app found", Toast.LENGTH_SHORT).show();
}

The email app opens with the address, subject and message already filled in, and the user presses Send.

Q.3: Long Questions 7 × 4

Write down steps, code and sketch screens to do following:

i.

You have to create three activities named Login, Admin, and Operator. On Login activity there should be two text boxes to enter username and password. If user enters username “admin” and password “abc” it should go to Admin activity. On the other hand, if user enters username “operator” and password “123” it should launch Operator activity.

Show solution

Steps: 1) create three activities (Login, Admin, Operator); 2) design the Login screen with two text boxes and a button; 3) read the username and password when the button is clicked; 4) compare them and start the right Activity; 5) show an error if a field is empty or the login is wrong.

Sketch of the Login screen:

+--------------------------+
|          Login           |
|  [ Username            ] |
|  [ Password            ] |
|        [  LOGIN  ]      |
+--------------------------+

Login layout (activity_login.xml):

<LinearLayout
    xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical"
    android:padding="20dp">

    <EditText
        android:id="@+id/edtUsername"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:hint="Username" />

    <EditText
        android:id="@+id/edtPassword"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:hint="Password"
        android:inputType="textPassword" />

    <Button
        android:id="@+id/btnLogin"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:text="Login" />

</LinearLayout>

LoginActivity.java:

public class LoginActivity extends AppCompatActivity {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_login);

        EditText edtUsername = findViewById(R.id.edtUsername);
        EditText edtPassword = findViewById(R.id.edtPassword);
        Button btnLogin = findViewById(R.id.btnLogin);

        btnLogin.setOnClickListener(v -> {

            String username = edtUsername.getText().toString().trim();
            String password = edtPassword.getText().toString().trim();

            if (username.isEmpty() || password.isEmpty()) {

                Toast.makeText(this,
                    "Username and password are required",
                    Toast.LENGTH_SHORT).show();

            } else if (username.equals("admin") && password.equals("abc")) {

                startActivity(new Intent(this, AdminActivity.class));

            } else if (username.equals("operator") && password.equals("123")) {

                startActivity(new Intent(this, OperatorActivity.class));

            } else {

                Toast.makeText(this,
                    "Invalid username or password",
                    Toast.LENGTH_SHORT).show();
            }
        });
    }
}

AdminActivity and OperatorActivity are two more Activities, each with its own layout (for example a TextView saying "Admin" or "Operator"). All three Activities must be declared in AndroidManifest.xml.

ii.

What is Fragment, how they are created and used in Android, describe in details.

Show solution

Fragment: a reusable part of an Activity's user interface with its own layout and lifecycle. It must be hosted by an Activity.

1. Fragment class:

public class StudentFragment extends Fragment {

    public StudentFragment() { }

    @Override
    public View onCreateView(LayoutInflater inflater,
                             ViewGroup container,
                             Bundle savedInstanceState) {

        return inflater.inflate(R.layout.fragment_student, container, false);
    }
}

2. Container in the Activity layout:

<androidx.fragment.app.FragmentContainerView
    android:id="@+id/fragmentContainer"
    android:layout_width="match_parent"
    android:layout_height="match_parent" />

3. Add it from the Activity:

getSupportFragmentManager()
    .beginTransaction()
    .replace(R.id.fragmentContainer, new StudentFragment())
    .commit();

The layout fragment_student.xml holds the Fragment's views. Use add(), replace() or remove() in a transaction to change fragments while the app runs.

Topic: Fragments
